# 归档材料说明

本目录保存仍有参考价值、但不应作为评审主入口的历史材料。归档是为了让仓库首页更清楚，不是删除内容。

## 目录

- `development_history/`：阶段性开发记录、V2/V3/V4 精度改良说明、冻结审计和旧 runbook。
- `technical_report_sources/v5_benchmark/`：旧 V5 benchmark 报告副本、图表、R/Python 生成脚本和 EchoNet 增强说明。
- `validation_docx_reports/`：各数据集验证报告的 DOCX 版本和打包件。
- `performance_runs/validation_speedopt/`：SpeedOpt、EchoBench smoke、本地服务测试和相关 JSON/CSV 运行记录。

正式技术报告请看仓库根目录的 [REPORTS.md](../REPORTS.md)。
