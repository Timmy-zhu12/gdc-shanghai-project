# Validation Reports

This directory stores generated validation reports copied from the dense validation workbench.

Raw datasets and generated feature caches are intentionally excluded. To reproduce the reports, use the separate local workbench:

```text
D:\cardioconsult_dense_validation
```

Included:

- Markdown reports in `reports/`
- Word reports in `reports_docx/`

The reports are for research and competition evaluation only.
